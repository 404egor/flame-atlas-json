# Зразки даних

Чотири файли у форматі контракту з [contracts/README.md](../../contracts/README.md). Назви ті самі,
що й у `data/processed`, тому сайт перемикається зі зразків на справжні дані зміною одного шляху.

| Файл | Що всередині |
|---|---|
| `tests.json` | 7 справжніх рядків з таблиць PSI: BASS-II, FLEX, SAFFIRE-I, SAFFIRE-II, ACME BRE (два дні), CFI-G. Показують одне значення, діапазон, перелік, наближення, рядок рівня «день тестів», відсутній тиск |
| `investigations.json` | 6 карток. Структура справжня, тексти з позначкою `FIXTURE PLACEHOLDER` — це не факти |
| `scenarios.json` | 5 сценаріїв. Числа, перелічені в `assumptions`, ще треба підтвердити джерелом |
| `meta.json` | паспорт збірки зразків |

Перевірка:

```bash
python3 contracts/validate.py data/fixtures
```

Правила:

- Значення в `raw` скопійовані з таблиць PSI дослівно, з одруківками заголовків.
- Зведені значення в зразках зроблені вручну. Це еталон для рушія зведення: він має відтворити їх із вихідних рядків.
- Тексти `FIXTURE PLACEHOLDER` і назви досліджень зі зразків не можна показувати в демо.
- Зразки змінює власник контрактів разом зі схемою, в одному коміті.
