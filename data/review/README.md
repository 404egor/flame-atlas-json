## 2. `qa-tests.csv` — вибірка тестів

Заголовок файла:

```
id,field,expected,actual,ok,note
```

- `id` — id запису з `tests.json`;
- `field` — шлях поля, наприклад `atmosphere.o2Pct`;
- `expected` — значення, яке ти бачиш у вихідному CSV (з одиницею);
- `actual` — значення в нашому записі;
- `ok` — `1` або `0`;
- `note` — що не так.

Обсяг: 40 записів, по 4–6 з кожної пріоритетної таблиці. Поля: паливо, O₂, тиск, потік, наслідок.

## 3. `qa-cards.csv` — вибірка тверджень з карток

```
investigationId,section,claim,sourceId,locator,found,faithful,note
```

- `found` — `1`, якщо твердження є в джерелі за вказаним місцем;
- `faithful` — `1`, якщо зміст передано без посилення чи спотворення.

Обсяг: по 2 твердження з кожної картки.

## 4. `golden-questions.md` — золоті питання для Ask

Формат запису:

```
### Q1
Question: Which experiments tested solid materials above 30% oxygen?
Expected investigations: PSI-..., PSI-...
Key fact: ... (sourceId, locator)
Answerable from PSI data: yes
```

Обсяг: 12 питань. Чотири з них мають бути без відповіді в даних PSI
(наприклад, про часткову гравітацію), щоб перевірити чесне «not found».

## 5. `pillars.md` — напрям безпеки кожного дослідження

Таблиця на 24 рядки: `ID, основний напрям, додаткові, чому (джерело)`.
Початкова гіпотеза лежить у `docs/03-data-sources.md`, розділ 3.
