# Роль D — Frontend: екрани, графіки, зручність

**Кому підійде:** тому, хто найшвидше збирає інтерфейси на React і має відчуття продукту.
**Місія:** зробити так, щоб науковець за хвилину зрозумів, що показує дашборд, і довіряв побаченому:
кожне число й твердження має видиме джерело.

## Зона відповідальності

- `apps/web/app/` — сторінки (крім `app/api/`).
- `apps/web/components/`, стилі, навігація, тексти інтерфейсу.
- Демо-режим: прямі посилання на три сценарії.

Інтерфейс англійською. Стек: Next.js App Router, Tailwind, shadcn/ui, Recharts.

## Що отримуєш і що віддаєш

| Від кого | Що |
|---|---|
| A | типи з `@flame/contracts`, `/api/ask`, `/api/explain` |
| C | функції `core` (rank, coverage, gaps, compare, filter), маршрути API |
| E | тексти пресетів, порядок демо, зауваження до зрозумілості |

| Кому | Що |
|---|---|
| E | робочий застосунок за публічним посиланням, знімки екрана для слайдів |

**Ти ніколи не чекаєш на дані.** З першої хвилини працюєш на `data/fixtures`: форми ті самі,
що й у справжніх файлів. Перехід на `data/processed` — заміна шляху імпорту.

## Задачі за фазами

### Старт (перші 45 хвилин, разом з B)
- [ ] `apps/web`: Next.js, Tailwind, shadcn/ui, Recharts. Каркас з навігацією:
      Scenario, Investigations, Tests, Coverage, Compare, Ask, Methodology.
- [ ] Перший деплой на Vercel. Посилання в чат команди.

### Фаза 1 (субота до 18:30): головний екран на фікстурах
- [ ] **Scenario:** пресети кнопками (ISS, Lunar habitat, Mars habitat, Pressurized rover, EVA suit)
      і власні значення: O₂ %, тиск кПа (поруч psi), гравітація, потік см/с, матеріали, фокус.
- [ ] Ранжований список: назва, абревіатура, бал, смужки складників балу, теги напряму безпеки,
      застереження, 3 найближчі тести.
- [ ] Стан сценарію в адресі сторінки (`?scenario=lunar-habitat`), щоб демо відкривалось за посиланням.

**Готово, коли:** за публічним посиланням видно ранжований список на фікстурах, пресети перемикаються.

### Фаза 2 (субота до 23:00): картка, таблиця, покриття, порівняння
- [ ] **Investigation:** усі розділи картки. Кожне твердження має маркер джерела; клік показує документ,
      сторінку, цитату й посилання на PSI або DOI. Позначка стану перевірки (`review.status`).
- [ ] **Tests:** таблиця з фільтрами (дослідження, стан палива, діапазони O₂, тиску, потоку, наслідок),
      перемикач «нормалізовані / вихідні колонки», кнопка Export CSV / JSON.
- [ ] **Coverage:** теплова карта «O₂ × тиск» з перемикачем на «O₂ × потік», фільтр стану палива,
      маркер поточного сценарію, порожні клітинки виділені, підпис про тести без значення по осі.
- [ ] **Compare:** вибір 2–4 досліджень, матриця атрибутів, рядки з відмінностями підсвічені.

**Готово, коли:** усі чотири екрани працюють на справжніх даних щонайменше для 10 досліджень.

### Фаза 3 (неділя до 13:00): Ask, пояснення, прогалини
- [ ] **Ask:** поле питання, відповідь потоком, пронумеровані джерела картками, стан «not found in PSI data»,
      3–4 приклади питань кнопками.
- [ ] Панель «Why this ranking» у списку: текст пояснення з джерелами плюс розклад балу.
- [ ] Список прогалин на екранах Scenario і Coverage (дані від `findGaps`).
- [ ] **Methodology:** джерела даних, схема пайплайна, метрики з `eval.json`, обмеження, використання AI.

### Фаза 4 (неділя до 17:00): полірування
- [ ] Порожні стани, завантаження, помилки на кожному екрані.
- [ ] Вигляд на ноутбуці й на проєкторі: великі шрифти в графіках, контраст.
- [ ] Заголовок сторінки, favicon, зображення для попереднього перегляду посилання.
- [ ] Знімки екрана для E. Перевірка публічного посилання в режимі інкогніто.

### Якщо лишився час
- Розділ Earth applications.
- Графік моделі межі займання (якщо C її зробить).

## Правила інтерфейсу

- Одиниці завжди поруч з числом. Тиск показуємо в кПа і в psi.
- `null` показуємо як «not reported», а не як 0 чи порожнє місце.
- Нормалізоване значення завжди дає доступ до вихідного (підказка або розгортання рядка).
- Жодного тексту від LLM без видимого джерела.
- Кольори напрямів безпеки однакові на всіх екранах.

## З ким синхронізуватись

- **C**, постійно: форми даних для Compare, Coverage і списку.
- **A**, у неділю зранку: формат потоку `/api/ask` і джерел.
- **E**: порядок демо, тексти, що незрозуміло сторонній людині.

## Ризики ролі

- Теплова карта з малою кількістю даних виглядає порожньою. Це і є повідомлення: підпиши її
  як карту прогалин, не намагайся заповнити.
- Забагато екранів. Якщо час тисне, Compare і Ask поступаються місцем Scenario, Investigation,
  Tests і Coverage.
