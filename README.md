# Flame Atlas — стартовий набір команди

Набір файлів для хакатону NASA Space Apps 2026, челендж «Flame in Freefall».
Його кладуть у корінь нового репозиторію. Коду тут ще немає: є план, контекст для AI-агентів,
контракти даних і зразки.

> Коли з'явиться код, цей README замінюється англійським README проєкту (роль B, неділя).
> Цей текст тоді переїжджає в `docs/kit-readme.md`.

## Як дати контекст агенту

1. Відкрий агента в корені репозиторію. Claude Code сам прочитає `CLAUDE.md` → `AGENTS.md`.
   Іншому агенту скажи: «Прочитай AGENTS.md».
2. Скопіюй стартовий промпт з кінця свого файла ролі.
3. Прочитай план, який запропонує агент, перш ніж дозволити писати код.
