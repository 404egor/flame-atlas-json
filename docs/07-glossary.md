# Глосарій: горіння простими словами

**Статус: чернетка.** Веде предметник з команди «Дані й AI». Кожне визначення треба звірити з джерелом
(сторінка челенджу, NASA Researcher's Guide to ISS Combustion Science, документи PSI)
і дописати посилання. Агенти використовують цей файл як словник, а не як джерело фактів для карток.

## Умови середовища

| Термін | Простими словами |
|---|---|
| **Microgravity (µg), мікрогравітація** | стан вільного падіння на орбіті. Сила тяжіння майже не відчувається |
| **Partial gravity, часткова гравітація** | Місяць — близько 1/6 земної, Марс — близько 3/8. Даних PSI для неї немає |
| **Buoyancy, плавучість** | на Землі гарячі гази легші за холодні й піднімаються, підтягуючи свіже повітря до полум'я. У мікрогравітації цього немає |
| **Oxygen concentration, частка кисню** | відсоток кисню в суміші газів за об'ємом. У таблицях буває як відсоток (`22.2`) або мольна частка (`0.21`, позначення `XO2`) |
| **Total pressure, тиск** | загальний тиск атмосфери. Одиниці в таблицях: psi, atm, bar, mmHg. Ми зводимо до кПа |
| **Exploration atmosphere** | атмосфера для баз і роверів з підвищеною часткою кисню і зниженим тиском. Сторінка челенджу називає ≥30% O₂ і ≤10.2 psi |
| **Diluent, розбавлювач** | інертний газ у суміші: азот (N₂), вуглекислий газ (CO₂), гелій (He). Від нього залежить, як легко гасне полум'я |
| **Flow velocity, швидкість потоку** | швидкість руху повітря повз полум'я, см/с. На кораблі її створює вентиляція |

## Полум'я

| Термін | Простими словами |
|---|---|
| **Diffusion flame, дифузійне полум'я** | паливо й кисень не змішані заздалегідь і зустрічаються в зоні горіння. Так горить свічка і так виглядає більшість пожеж |
| **Opposed flow, зустрічний потік** | полум'я поширюється назустріч потоку повітря |
| **Concurrent flow, супутній потік** | полум'я поширюється в напрямку потоку повітря |
| **Coflow** | паливо й повітря подаються паралельно в одному напрямку (пальники SPICE, SLICE, ACME) |
| **Normal / inverse flame** | звичайне: паливо подається в окисник. Обернене: окисник подається в паливо. Обидва є в таблицях ACME |
| **Flame spread rate, швидкість поширення** | як швидко край полум'я рухається по матеріалу, мм/с |
| **Ignition, займання** | момент, коли матеріал починає горіти самостійно |
| **Extinction, згасання** | полум'я гасне. У таблицях: `SE` (self-extinguished, згасло саме), `FT` (flow terminated, зупинили подачу) |
| **Flammability limit, межа горючості** | межа умов (частка кисню, потік, тиск), за якою матеріал уже не підтримує горіння |
| **Blowoff** | полум'я здуває надто сильний потік |
| **Quenching** | полум'я гасне через нестачу кисню або втрати тепла при надто слабкому потоці |

## Дим і виявлення

| Термін | Простими словами |
|---|---|
| **Soot, сажа** | дрібні частинки вуглецю, що утворюються в полум'ї й дають йому жовтий колір |
| **Smoke point, точка димоутворення** | розмір полум'я, за якого воно починає виділяти сажу назовні. Предмет дослідження SPICE |
| **Smoke aerosol, димовий аерозоль** | частинки диму в повітрі. Їхній розмір визначає, який тип датчика їх помітить |
| **Aging, старіння диму** | з часом частинки злипаються й більшають. Колонки `Aging Duration`, `aging time` у SAME і SAME-R |

## Краплі та холодне полум'я

| Термін | Простими словами |
|---|---|
| **Droplet combustion, горіння краплі** | у мікрогравітації крапля палива горить кулястим полум'ям. Зручна модель для вивчення гасіння |
| **Burning rate, швидкість вигоряння** | як швидко зменшується крапля |
| **Extinction diameter** | діаметр краплі в момент, коли видиме полум'я згасло |
| **Cool flame, холодне полум'я** | горіння при значно нижчій температурі, майже невидиме. Предмет досліджень CFI і CFI-G |

## Позначення в таблицях ACME

| Позначення | Значення |
|---|---|
| `XO2`, `Xf`, `Xfuel` | мольна частка кисню, палива |
| `Zst` | стехіометрична частка суміші (характеристика складу в зоні горіння) |
| `Tad (K)` | адіабатична температура полум'я, розрахункова величина |
| `mfuel`, `mN2`, `mtot (mg/s)` | масова витрата палива, азоту, сумарна |
| `MFC` | регулятор масової витрати газу |
| `RAMPED` | параметр плавно змінювали під час тесту, одного значення немає |

## Обладнання

| Скорочення | Що це |
|---|---|
| **ISS** | Міжнародна космічна станція |
| **CIR** | Combustion Integrated Rack, стійка для дослідів з горіння на МКС |
| **MDCA** | Multi-user Droplet Combustion Apparatus, вставка в CIR для крапель (FLEX, FLEX-2, CFI) |
| **ACME** | Advanced Combustion via Microgravity Experiments, вставка в CIR для газових полум'їв (6 експериментів) |
| **MSG** | Microgravity Science Glovebox, рукавичний бокс (BASS, BASS-II, SPICE, SLICE) |
| **Cygnus** | вантажний корабель; у ньому після відстикування від МКС проводили Saffire |

## Матеріали

| Назва | Що це |
|---|---|
| **PMMA** | поліметилметакрилат, оргскло. Типовий модельний твердий матеріал |
| **SIBAL fabric** | тканина з бавовни й скловолокна, зразки в BASS і Saffire |
| **Kapton, Teflon, silicone** | полімери ізоляції дротів і деталей; у SAME їх перегрівали, щоб отримати дим |
