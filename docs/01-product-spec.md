# Продукт: що саме будуємо

## 1. Вимоги челенджу і наша відповідь

| Вимога зі сторінки челенджу | Що в продукті |
|---|---|
| Дашборд «summarizes, ranks, and interprets» дослідження з горіння | картки досліджень, ранжування під сценарій, прогалини в даних |
| Знаходити дослідження, найрелевантніші для безпеки екіпажу в конкретному середовищі | екран Scenario з готовими сценаріями й ранжованим списком |
| Витягувати дані для прогнозного моделювання горючості й пожежних сценаріїв | єдина таблиця тестів з фільтрами й експортом CSV і JSON |
| Показувати дослідження, корисні для нових систем пожежної безпеки | напрями prevention / detection / suppression і розділ «fire-safety relevance» у картці |
| Атрибути: мета, паливо й геометрія, умови, відмінності між тестами, датчики | картка дослідження з матрицею «що змінювалось між тестами» |
| Часткової гравітації в даних немає; результати 0 g і 1 g задають межі | карта покриття і список прогалин |
| Поза межами: ракети, паливо | не робимо |

## 2. Користувачі

- **Інженер пожежної безпеки бази чи ровера.** Хоче знати, які досліди проводили в умовах, близьких
  до його середовища, і де даних немає.
- **Дослідник або аспірант-модельник.** Хоче відфільтровану таблицю тестів з умовами й наслідками.
- **Студент або викладач.** Хоче швидко зрозуміти, що вивчало дослідження.

## 3. Головна знахідка

Продукт будується навколо одного питання: **скільки з того, що NASA вже дослідила, стосується атмосфери
місячної бази?** Відповідь — число, яке рахує пайплайн (задача DA-14) і показує сайт (задача PR-9):
скільки тестів твердих матеріалів проведено при кисні від 30% і тиску до 70.3 кПа і скільки при
частковій гравітації. Це число стоїть на головному екрані й на слайдах.

## 4. Три демо-сценарії

1. **Lunar habitat.** 34% кисню, 56.5 кПа, 0.165 g, тверді матеріали, фокус prevention.
   Очікуємо вгорі ACME BRE, BASS-II, Saffire. Карта покриття показує порожнечу біля умов бази.
2. **ISS, виявлення диму.** 21% кисню, 101.3 кПа, 0 g, фокус detection. Очікуємо SAME, SAME-R, DAFT.
3. **Гасіння в герметичному ровері.** Фокус suppression, рідке паливо. Очікуємо FLEX, FLEX-2.

Ці очікування — перевірка здорового глузду для ваг ранжування. Числа сценаріїв підтверджує предметник.

## 5. Екрани

| Екран | Зміст |
|---|---|
| **Scenario** (головна) | сценарії й власні значення → ранжований список з балом, складниками балу, найближчими тестами; блок зі знахідкою і трьома головними прогалинами |
| **Tests** | єдина таблиця: фільтри, зведені й вихідні значення, експорт |
| **Coverage** | сітка «кисень × тиск», мітка сценарію, порожні клітинки, список прогалин з числами |
| **Investigations** | картки: мета, паливо, умови, вимірювання, значення для безпеки, статті; матриця «що змінювалось між тестами»; кожне твердження з джерелом |
| **Methodology** | джерела, підготовка даних, результат ручної перевірки, обмеження, використання AI |

## 6. Що робимо зараз і що пізніше

**Зараз (без LLM на сайті):**
- п'ять екранів з таблиці вище;
- публічне посилання на сайт і репозиторій;
- подання: тексти, слайди, джерела, опис використання AI.

LLM працює тільки під час підготовки даних: пропонує маппінги таблиць, розбирає назви матеріалів,
пише тексти карток.

**Пізніше, якщо лишиться час:**
- живий Evidence brief: LLM пише короткий підсумок для сценарію, код звіряє кожне число й номер тесту;
- екран Compare для двох досліджень.

**Не робимо:**
- пошук по документах і чат;
- великі PDF-звіти, презентації, показники датчиків, відео (малі файли ReadMe читаємо: вони пояснюють колонки таблиць);
- модель межі займання й будь-які прогнози;
- логін, базу даних, серверну частину.

## 7. Чим відрізняємось

1. **Сценарій замість пошукового рядка.** Користувач задає середовище числами.
2. **Єдина таблиця.** 22 різнорідні таблиці NASA зведені до однієї схеми з вихідними значеннями поруч.
3. **Карта прогалин і знахідка з числом.** Показуємо не лише те, що є, а й те, чого бракує.
4. **Перевірювана чесність.** Кожне число веде до рядка таблиці NASA; точність зведення виміряна
   на ручній вибірці й показана на сторінці Methodology.

## 8. Критерії готовності демо

- Три демо-сценарії відкриваються за прямим посиланням і дають очікуваний верх списку.
- Знахідка на головному екрані збігається з розрахунком у `data/review/findings.md`.
- Сторінка Methodology показує, скільки значень перевірено вручну і скільки з них правильні.
- Сайт відкривається за публічним посиланням у режимі інкогніто.
