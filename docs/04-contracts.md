# Контракт даних

Контракт між командою «Дані й AI» (пише дані) і командою «Продукт» (читає дані) лежить у папці
[`contracts/`](../contracts/README.md). Це єдина межа між командами.

| Що | Де |
|---|---|
| Опис полів і правил людською мовою | [contracts/README.md](../contracts/README.md) |
| JSON-схеми, джерело правди | [contracts/schema/](../contracts/schema) |
| Типи TypeScript для сайту | [contracts/types.ts](../contracts/types.ts) |
| Перевірка даних | [contracts/validate.py](../contracts/validate.py) |
| Зразки даних у цьому форматі | [data/fixtures/](../data/fixtures) |

## Коротко

- Сайт читає чотири файли: `tests.json`, `investigations.json`, `scenarios.json`, `meta.json`.
- У `data/fixtures` і `data/processed` файли мають однакові назви й формат. Команда «Продукт» починає на зразках.
- Перед кожним комітом даних запускається перевірка:

```bash
python3 contracts/validate.py data/processed
```

- `null` означає «у джерелі не вказано». Одиниці фіксовані: %, кПа, см/с, мм, с.
- Числа з діапазоном записані парою `Min` / `Max`. Вихідний рядок таблиці завжди лежить у `raw`.
- Рядок таблиці не завжди є окремим тестом: тип рядка записаний у полі `granularity`.
- Бал релевантності, сітку покриття й прогалини рахує сайт. У файли вони не входять.
